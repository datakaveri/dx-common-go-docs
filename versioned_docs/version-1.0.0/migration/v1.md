# Migrating to v1.0.0

v1.0.0 is the product of five refactoring waves (W0–W4). If your service compiled against a pre-wave snapshot, apply these in order — every step is mechanical unless marked **behavioral**.

## Imports & names (W3)

| Old | New |
|---|---|
| `dx-common-go/errors` (aliased `dxerrors`) | `dx-common-go/dxerrors` — drop the alias |
| `errors.BaseDxError` | `dxerrors.Error` (constructors return `*Error`) |
| `dx-common-go/transport/headers` | `dx-common-go/auth/headers` |
| `dx-common-go/grpc/appidpb` | `dx-common-go/auth/appid/appidpb` |
| `auth.UserFromCtx` / `resolver.OriginFromCtx` / `middleware.RequestIDFromCtx` / `auditing.FromCtx` | same names with `…FromContext` |

## Constructors (W3)

| Old | New |
|---|---|
| `jwt.Middleware(cfg)` (panicked) | `jwt.Middleware(cfg) (mw, error)` — or `jwt.MustMiddleware(cfg)` at boot |
| `resolver.Middleware(cfg)` (panicked) | `resolver.Middleware(cfg) (mw, error)` / `MustMiddleware` |
| `openapi.ValidationMiddleware(l, cfg)` (panicked) | returns `(mw, error)` / `MustValidationMiddleware` |
| `client.NewPool(cfg, …)` | `client.NewPool(ctx, cfg, …)` |
| `redis.NewClient(cfg)` / `esclient.New(cfg)` / `s3.NewClient(cfg)` / `sts.NewVendor(cfg)` | same, with leading `ctx` |

## HTTP contract (W2)

| Old | New |
|---|---|
| `pagination.Info` / `pagination.NewInfo` | `response.PageInfo` / `response.NewPageInfo` (wire shape unchanged) |
| `errors.HandleError(w, err)` | `dxerrors.WriteServerError(w, err, nil)` |
| `errors.HandleDatabaseError(w, err)` | `dxerrors.WriteServerError(w, dxerrors.MapPostgresError(err), logFn)` |
| `errors.HandleValidationError/NotFound/Authorization/StatusCode…` | compose `WriteError` + the matching constructor |
| `response.URN<Service>…` constants | your own service-local constants / `NewServiceWriter` prefix |
| `err.(errors.DxError)` type assertions | `dxerrors.From(err)` — **behavioral**: wrapped taxonomy errors now surface correctly instead of flattening to 500 |

## Messaging (W1)

| Old | New |
|---|---|
| `pub.PublishJSON(exchange, key, v)` | `pub.PublishJSON(ctx, exchange, key, v)` — **behavioral**: caller deadline applies; spans link into the caller's trace |
| `rabbitmq.Client.Publish/PublishJSON` | `ReliablePublisher` |
| `rabbitmq.Client.Consume` | `ConsumerRunner` — **behavioral**: consumers now survive broker restarts (the old path died silently on reconnect) |
| comparing `Outcome` to `0` | impossible: `Ack == 1`; invalid outcomes dead-letter — **behavioral** safety net |

## Lifecycle (W4)

| Old | New |
|---|---|
| `srv.Start()` in multi-component services | `srv.Run(ctx)` with one `signal.NotifyContext` shared by all components |
| `srv.StartTLS()` | deleted — set `TLSCertFile`/`TLSKeyFile` in config; `Run`/`Start` serve HTTPS |

## Removed without replacement (W0 — all had zero consumers)

`model` package · `cache.RedisCache`/`CacheHelper`/`CacheKey` · `config.LoadInto` · `response` builder + legacy paginated fields · the `middleware` audit system + `Get*FromCtx` helpers + `MetricsHandler` + `StandardStack` (→ `Standard`) · `errors.GlobalErrorHandler` · deprecated `pagination` types.

## Contract fixes worth knowing (W1)

- `config.LoadService` now **fails on malformed config files** (previously booted on defaults) and calls your `Validate() error` if present.
- `cache.Cache` miss semantics are normative: `Get → (value, ok, error)`; a miss is never an error.
- OpenAPI validation 400s now name the offending parameter/field.
